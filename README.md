# 뱀주사위놀이 · 육성 버전

1970~80년대 문방구에서 팔던 육성출판사 「뱀주사위놀이」 보드를 웹 게임으로 옮긴 것입니다.
사람과 컴퓨터가 번갈아 주사위를 굴려 1번에서 출발해 100번 칸에 먼저 닿으면 이깁니다.

**▶ [바로 플레이](https://civilian7.github.io/snake-dice-game/)**

## 특징

- **원본 그림 보드**와, 같은 배치를 코드로 다시 그린 **레트로 보드** 중에 고를 수 있습니다.
- 주사위가 3D로 구르며, 결과가 나오는 과정을 눈으로 볼 수 있습니다.
- 고속도로 13곳과 뱀 12곳은 원본 보드와 같고, 각 칸의 교훈이 카드로 뜹니다.
- 효과음은 음원 파일 없이 Web Audio 로 그때그때 합성합니다.
- 휴대폰 세로·가로 모두 지원합니다.

## 규칙

| | |
|---|---|
| 시작 | 두 말 모두 1번 칸 |
| 차례 | 사람이 먼저, 그다음 컴퓨터가 자동으로 |
| 고속도로 | `4→16 8→12 18→38 20→74 24→36 32→56 34→46 40→60 48→54 70→88 76→86 80→100 90→92` |
| 뱀 | `22→2 28→6 30→10 44→26 58→42 66→14 68→52 72→50 84→62 94→64 96→82 98→78` |
| 100번 칸 | 정확히 도달해야 승리. 넘어가면 넘어간 만큼 되돌아오고, 되돌아온 칸의 뱀·고속도로는 발동한다 |
| 연쇄 | 뛰어오르거나 미끄러진 칸에서 또 발동하지 않는다 |

**새 게임** 창에서 보드와 규칙을 고릅니다. 아래 둘은 원본 판에 근거가 없는 변형 규칙이라
기본으로 꺼져 있습니다.

| 옵션 | 켜면 |
|---|---|
| 6이 나오면 한 번 더 | 6이 나온 사람이 이어서 굴린다. 한 차례에 3연속이면 거기서 끝 |
| 앞말 잡기 | 뱀·고속도로까지 끝난 최종 칸에 상대 말이 있으면 그 말은 1번으로 |

## 조작

- **주사위 굴리기** 버튼, `Space` 키, 또는 주사위를 직접 누르기
- 상단에서 새 게임 · 게임 안내 · 효과음 켜고 끄기

## 실행

빌드 도구도 의존성도 없습니다. `index.html` 을 브라우저로 열면 그대로 실행됩니다.

```
git clone https://github.com/civilian7/snake-dice-game.git
cd snake-dice-game
start index.html          # macOS 는 open, Linux 는 xdg-open
```

## 만듦새

`index.html` 한 파일에 CSS·JS 가 모두 들어 있습니다. 안쪽은 이렇게 나뉩니다.

| 구획 | 하는 일 |
|---|---|
| 보드 데이터 | 고속도로·뱀·칸별 교훈 |
| 좌표 | 부스트로페돈 배열(1번 좌하단, 100번 좌상단) |
| 규칙 계층 | `resolveMove()` — DOM 을 모르는 순수 함수. 애니메이션은 그 결과를 재생만 한다 |
| 렌더링 | CSS 격자 + SVG 오버레이(뱀·고속도로) |
| 주사위 | CSS 3D 큐브. 값은 굴리기 시작 때 확정되고 그 면으로 착지한다 |
| 효과음 | Web Audio 합성 |
| 턴 상태머신 | 굴림 → 이동 → 이벤트 → 밀어내기 → 승패 |

원본 그림 모드의 격자 위치는 이미지의 행·열 평균 밝기에서 칸 경계를 검출해
최소자승으로 맞췄습니다(열 간격 50.9px, 행 간격 63.0px).

설계 문서는 [`docs/superpowers/specs`](docs/superpowers/specs) 에 있습니다.

## 출처와 권리

- 보드 그림 `board.webp` 와 고속도로·뱀 배치는
  [나무위키 뱀주사위놀이](https://namu.wiki/w/%EB%B1%80%EC%A3%BC%EC%82%AC%EC%9C%84%EB%86%80%EC%9D%B4)
  문서에서 가져왔습니다. 원본은 **육성출판사 「뱀주사위놀이」(등록원 제5386호, 값 30원)** 이며,
  **저작권은 원 권리자에게 있습니다.** 이 저장소는 비영리·기록 목적의 재현입니다.
  권리자 또는 정당한 이해관계인의 요청이 있으면 즉시 내리겠습니다.
- 칸별 교훈 문구는 원본 보드의 그림을 따랐고, 원문이 남아 있지 않은 칸은 그림의 정황에
  맞추어 새로 쓴 것입니다.
- **그림을 뺀 나머지 코드는 MIT 라이선스**입니다. `board.webp` 는 MIT 적용 대상이 아닙니다.
  그림 없이도 「레트로」 보드로 게임이 온전히 동작합니다.
