# 뱀주사위놀이 · 육성 버전

1970~80년대 문방구에서 팔던 육성출판사 「뱀주사위놀이」 보드를 웹 게임으로 옮긴 것입니다.
두 말이 번갈아 주사위를 굴려 1번에서 출발해 100번 칸에 먼저 닿으면 이깁니다.
**컴퓨터와** 두거나, **온라인으로 다른 사람과** 둘 수 있습니다.

**▶ [바로 플레이](https://civilian7.github.io/snake-dice-game/)**

## 특징

- **온라인 대전** — 방 코드로 두 사람의 브라우저를 직접 잇습니다(WebRTC P2P). 서버가 없어
  **GitHub Pages 그대로 굴러갑니다.** 한 사람이 방을 만들어 코드를 알려 주면 상대가 그
  코드로 참가하고, 연결되면 번갈아 굴립니다. 자기 차례에 **5초** 안에 굴리지 않으면
  자동으로 굴러가 판이 멈추지 않습니다.
- **컴퓨터와 대전** — 혼자서도 한 판. 컴퓨터 차례는 자동으로 진행됩니다.
- 문방구에서 팔던 **원본 판** 그림 한 장. 격자·칸 번호·뱀·고속도로가 모두 그림 안에 있습니다.
- 주사위가 3D로 구르며, 결과가 나오는 과정을 눈으로 볼 수 있습니다.
- 고속도로 13곳과 뱀 12곳에 도착하면 각 칸의 이야기가 카드로 뜹니다.
- 효과음은 음원 파일 없이 Web Audio 로 그때그때 합성합니다.
- 휴대폰 세로·가로 모두 지원합니다.

## 규칙

| | |
|---|---|
| 시작 | 두 말은 보드 밖에서 대기. 처음 굴린 눈만큼 판에 올라선다 (3이면 3번 칸부터) |
| 선 | 무작위로 정해진다. 판이 끝난 뒤 **계속하기**로 이어 가면 **진 쪽이 선**을 잡는다 |
| 차례 | 번갈아 굴린다. 컴퓨터 차례는 자동 진행, 온라인은 상대가 굴릴 때까지 기다린다 |
| 고속도로 | `4→16 8→12 18→38 20→74 24→36 32→56 34→46 40→60 48→54 70→88 76→86 80→100 90→92` |
| 뱀 | `22→2 28→6 30→10 44→26 58→42 66→14 68→52 72→50 84→62 94→64 96→82 98→78` |
| 끝내기 | 100번 칸에 닿으면 승리. 눈이 남아 넘어가도 그냥 이긴다 (99에서 6이면 거기서 끝) |
| 연쇄 | 뛰어오르거나 미끄러진 칸에서 또 발동하지 않는다 |

## 온라인 대전

서버 없이 두 브라우저를 방 코드로 직접 잇습니다(PeerJS · WebRTC).

1. 한 사람이 **새 게임 → 온라인 대전 → 방 만들기**. 다섯 글자짜리 **방 코드**가 나옵니다.
2. 그 코드를 상대에게 알려 줍니다.
3. 상대는 **방 참가하기**에 코드를 입력해 들어옵니다.
4. 연결되면 판이 자동으로 열립니다. 선은 무작위, **자기 차례에만** 굴릴 수 있습니다.

자기 차례에 5초 안에 굴리지 않으면 자동으로 굴러갑니다. 상대가 창을 닫거나 연결이
끊기면 알려 줍니다. 두 사람 모두 인터넷에 연결돼 있어야 합니다.

## 조작

- **주사위 굴리기** 버튼, `Space` 키, 또는 주사위를 직접 누르기
- 상단에서 새 게임 · 게임 안내 · 효과음 켜고 끄기

## 실행

빌드 도구도 의존성도 없습니다. `index.html` 을 브라우저로 열면 그대로 실행됩니다.
(온라인 대전만 인터넷과 PeerJS 스크립트를 쓰고, 컴퓨터 대전은 오프라인에서도 됩니다.)

```
git clone https://github.com/civilian7/snake-dice-game.git
cd snake-dice-game
start index.html          # macOS 는 open, Linux 는 xdg-open
```

## 만듦새

`index.html` 한 파일에 CSS·JS 가 모두 들어 있습니다. 안쪽은 이렇게 나뉩니다.

| 구획 | 하는 일 |
|---|---|
| 보드 데이터 | 고속도로·뱀·칸별 이야기 |
| 좌표 | 부스트로페돈 배열(1번 좌하단, 100번 좌상단) |
| 규칙 계층 | `resolveMove()` — DOM 을 모르는 순수 함수. 애니메이션은 그 결과를 재생만 한다 |
| 렌더링 | 원본 판 그림 한 장(`board.webp`) 위에 좌표용 격자와 말을 얹는다 |
| 주사위 | CSS 3D 큐브. 값은 굴리기 시작 때 확정되고 그 면으로 착지한다 |
| 효과음 | Web Audio 합성 |
| 턴 상태머신 | 굴림 → 이동 → 이벤트 → 승패 |
| 온라인 대전 | PeerJS(WebRTC) P2P. 두 쪽이 **같은 주사위 값**을 같은 `resolveMove()` 에 넣어 상태를 늘 일치시킨다 |

격자 위치는 `board.webp` 의 행·열 평균 밝기에서 칸 경계를 검출해 최소자승으로
맞췄습니다(열 간격 50.9px, 행 간격 63.0px).

설계 문서는 [`docs/superpowers/specs`](docs/superpowers/specs) 에 있습니다.
